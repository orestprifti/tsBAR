# TS-BAR
This repository contains the replication code for the paper "Broken Adaptive Ridge in High-Dimensional Vector Autoregressions", Gianluca Cubadda, Luca Margaritella, Orest Prifti (2027).

## Replication
Run the files in the following order:
1. `code/01_data_cleaning.R`
2. `code/02_monte_carlo.R`
3. `code/03_empirical_application.R`
4. `code/04_figures_tables.R`

All tables and figures are saved in the `output/` directory.
